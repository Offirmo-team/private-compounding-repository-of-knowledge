# Comments on the paper

## Sided exercises: the paper doesn't say

4 of the 12 exercises involve a side: step-up onto chair (5), lunge (10), push-up and rotation (11), side plank (12).

The paper never specifies how to handle sides (alternate every rep? split the bout? one bout per side?). Checked in both
the transcription and the original PDF text: the only "alternate" refers to alternating muscle groups between stations.
The photos only show a single side.

We can infer from the constraints the paper DOES state:

- 12 stations × 30s, 10s transitions, "approximately 7 minutes" (12 × 30s + 11 × 10s = 7:50)
- a 30s bout is sized for 15 to 20 repetitions = one set
- balance of strength: "you would not want to prescribe five exercises for one body part while only prescribing one for
  another"

### Dynamic exercises (step-up, lunge, push-up and rotation) → alternate sides every rep

- one 30s station = one set of 15-20 reps, both sides share it
- photo 10A shows the lunge returning to feet-together standing between reps, consistent with alternating legs

### Isometric exercise (side plank) → no clear answer

| Option                           | Pros                                    | Cons                                                                                                                       |
| -------------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 15s / 15s within the 30s station | respects the 12 stations / ~7min design | 15s is a light hold per side                                                                                               |
| one side per round, switch next  | respects the design                     | unbalanced with an odd number of rounds (1 or 3)                                                                           |
| 30s / transition / 30s           | full hold on each side                  | 13 stations, +40s per round (7:50 → 8:30), 60s of core work vs. 30s for the crunch and the plank, 2 core stations in a row |

## Decision (for this app)

- dynamic sided exercises: alternate every rep
- side plank: 30s on each side as separate stations. We accept the longer circuit and imbalance in exchange for a
  meaningful hold on each side.
